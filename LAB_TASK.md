Null-safety:

Dart – это объектно-ориентированный язык с классами и наследованием на основе примесей (mixin). Каждый объект является экземпляром класса, и все классы, кроме Null, наследуются от Object.
Язык Dart обеспечивает надежную защиту от нулевых значений.
Безопасность при работе с нулевыми значениями предотвращает ошибку, возникающую в результате непреднамеренного доступа к переменным, которым присвоено значение null. Эта ошибка называется ошибкой разыменования нулевого значения. Ошибка разыменования нулевого значения возникает при обращении к свойству или вызове метода выражения, которое возвращает null. Благодаря безопасности при работе с нулевыми значениями компилятор Dart обнаруживает эти потенциальные ошибки во время компиляции.
Null-safety вводит три ключевых изменения:
1.	При указании типа для переменной, параметра или другого соответствующего компонента вы можете контролировать, допускает ли тип значения NULL null. Чтобы разрешить значение NULL, добавьте ? в конец объявления типа.

String? name  // Nullable type. Can be `null` or string.

String name   // Non-nullable type. Cannot be `null` but can be string.

2.	Перед использованием переменные необходимо инициализировать. Переменные, допускающие значение null, по умолчанию имеют значение null, поэтому они инициализируются автоматически. Dart не устанавливает начальные значения для типов, не допускающих значение null, таким образом необходимо задать начальное значение Non-nullable переменных. Всё это необходимо для предотвращения доступа к параметрам или вызова методов переменных, которые могут быть null, в то время как null не поддерживает используемое обращение 

3.	Null ничего не знает о поведении объекта, в связи с чем, когда вызывается какой-либо метод у переменной, происходит ошибка, кроме тех случаев когда null поддерживает их вызов (например, toString() или hashCode)

Null-aware операторы
•	?? (оператор if-null)
•	?. (условный доступ к свойству, вернет null если слева null)
•	??= (присваивание если слева null)

Чтение данных с клавиатуры

Для ввода данных с клавиатуры через терминал необходимо импортировать библиотеку dart:io, которая позволяет работать с операциями ввода-вывода, файлами, сокетами, HTTP и т.д. Несмотря на то, что при инициализации строковой переменной или в функции print можно использовать кириллицу, с ее вводом через терминал все не так однозначно. Если явно не указать, что потоки ввода-вывода будут работать в кодировке utf-8, считается пустая строка.

import 'dart:io';
import 'dart:convert';

void main() {
  // Устанавливаем кодировку для потока вывода,
  // чтобы не было проблем с кириллицей
  stdout.encoding = utf8;
  print('Введите строковое значение');
  // Явно указываем кодировку utf8 для корректного ввода кириллицы
  String? srt = stdin.readLineSync(encoding: utf8); 
  print(srt); // Привет!

  print('Введите целочисленное значение');
  String? input = stdin.readLineSync(); // синхронный ввод данных
  // Например, вводим 14
  print(input?.runtimeType); // String

  var inputInt = int.tryParse(input!); // перевод строки в число
  print(inputInt.runtimeType); // int
  
  print('Введенное значение: $inputInt');
}


Объектно-ориентированное программирование (ООП)

Как уже было сказано, Dart – объектно-ориентированный язык. По своему синтаксису Dart очень похож на семейство языков C (Си) – (C++, C#, Java, Kotlin и т. д.).
Основные концепции те же:
•	Классы, объекты, наследование, инкапсуляция, полиморфизм
•	Ключевые слова: class, extends, implements, abstract, static, final
•	Конструкторы, методы, поля
•	this, super, @override

class Person {
  String name;
  int age;
  
  Person(String name, int age) {
    this.name = name;  // явное присваивание
    this.age = age;
 // конструктор
  
  void greet() {
    print('Hello, I am $name');
  }
}

class Student extends Person {
  String university;
  
  Student(super.name, super.age, this.university);
  
  @override
  void greet() {
    super.greet();
    print('I study at $university');
  }
}

Асинхронное программирование и изоляты
Библиотеки Dart полны функций, которые возвращают значения Future или Stream объектов. Эти функции являются асинхронными: они возвращают значение после подготовки потенциально трудоемкой операции (например, ввода-вывода), не дожидаясь ее завершения.
Ключевые слова async и await поддерживают асинхронное программирование, позволяя писать асинхронный код.
Для использования этого метода await код должен находиться внутри функции, помеченной как async:
Future<void> checkVersion() async {
  var version = await lookUpVersion();
  // Do something with version
}

Добавление ключевого слова async к функции приводит к тому, что она возвращает объект Future.
//String lookUpVersion() => '1.0.0';
Future<String> lookUpVersion() async => '1.0.0';

-----------------------------------------

import 'dart:async';

int add() => 10 + 15;

void main(List<String> arguments) {
  var firstFuture = Future<int>(add);
  Future(()=> print('Oo'));
  firstFuture.then((value) => print(value));
  print('завершение main');
}
/* завершение main
   25
   Oo */

Поток (Stream) в Dart – это последовательность асинхронных событий, которые подразделяются на три типа:
 событие данных (элемент потока);
 событие ошибки;
 событие "done", оповещающее всех слушателей (тех, кто подписался на поток) о его завершении.
Для управления потоками в Dart используются следующие классы:
1 Stream. Представляет асинхронный поток данных. Слушатели могут подписаться на получение уведомлений о появлении новых событий данных.
2 EventSink. Обратный поток, добавление событий данных в который направляет эти данные в подключенный поток.
3 StreamController. Упрощает управление потоками, автоматически создавая поток и приемник, а также предоставляя методы для управления поведением потока.
4 StreamSubscription. Экземпляры этого класса могут сохранять ссылку на подписку, что позволяет им приостанавливать, возобновлять или отменять поток данных.

Stream<int> myGenerator(int last) async* {
  for (var i = 0; i <= last; i++) {
    yield i; 
  }
}

void createGenerator(int lastValue) async {
  var stream = myGenerator(lastValue);
  // слушаем поток и выводим получаемые данные в терминал
  stream.listen((s) => print(s)); 
}

void main(List<String> arguments) {
  print('Запуск main');
  createGenerator(20);
  print('Завершение main');
}
/* Запуск main
   Завершение main
   0
   ...
   20 */


Изоляты следует использовать всякий раз, когда ваше приложение обрабатывает достаточно большие вычисления, чтобы временно блокировать другие вычисления. Наиболее распространенный пример – приложения Flutter, когда необходимо выполнить большие вычисления, которые в противном случае могли бы привести к зависанию пользовательского интерфейса.

import 'dart:isolate';
import 'dart:io';
import 'dart:convert';

const String filename = 'with_keys.json';

void main() async {
  // Read some data.
  final jsonData = await Isolate.run(_readAndParseJson);

  // Use that data.
  print('Number of JSON keys: ${jsonData.length}');
}

Future<Map<String, dynamic>> _readAndParseJson() async {
  final fileData = await File(filename).readAsString();
  final jsonData = jsonDecode(fileData) as Map<String, dynamic>;
  return jsonData;
}
